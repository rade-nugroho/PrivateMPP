```bash

# Option B — compare two on-disk directory snapshots

```

`trailmark diff --help`:

```text
usage: trailmark diff [-h] [--language LANGUAGE] [--repo REPO] [--json]
                      before after

positional arguments:
  before                Path or git ref for the 'before' snapshot
  after                 Path or git ref for the 'after' snapshot

options:
  --language LANGUAGE   Source language (default: python)
  --repo REPO           Repository root used to resolve git refs
                        (default: cwd; ignored when paths are directories)
  --json                Emit the structured diff as JSON instead of a report
```
