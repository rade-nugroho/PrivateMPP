## Module-graph caveat

When asked for `module-deps` (see `DIAGRAMMING_CODE.md`), trailmark 0.3.0's TS frontend reports **"No import edges found"** for any of the three roots tried (`packages/`, `packages/agent/src`, `packages/per-client/src`). Function-call edges and class containment **do** resolve correctly, so call-graph, complexity, and class-diagram outputs are reliable; module-deps is not. Treat the `Dependencies:` line of the summary above as the authoritative module-level fact for this version of the tool.
