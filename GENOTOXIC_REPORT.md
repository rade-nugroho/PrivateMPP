## Why genotoxic was not attempted

Per the skill's own gating language: "Reads survived mutants, unnecessary test statements, and call graph data to identify false positives, missing test coverage, and fuzzing targets." With no test suite to mutate against, the tool has nothing to compare survived vs killed mutants — every mutant would survive vacuously, producing 100% noise.

I did **not** install Stryker, scaffold a test suite, or fabricate tests, because:

- The skill brief explicitly says "only if reasonable time" and lists "no framework or tests fail" as a stop condition.
- Inventing a test suite would corrupt the maturity baseline measured in `CODE_MATURITY_ASSESSMENT.md`.

## What needs to exist before this skill produces value

A practical bootstrap path for this monorepo (TypeScript + ESM + Next.js):

1. **Add Vitest** to the workspace.
   ```bash
   pnpm add -Dw vitest @types/node
   pnpm add -D --filter @private-mpp/per-client vitest
   pnpm add -D --filter @private-mpp/agent vitest
   pnpm add -D --filter @private-mpp/mpp-bridge vitest
   pnpm add -D --filter @private-mpp/web vitest @vitejs/plugin-react
   ```
2. **Author seed tests** for the trailmark hotspots (CC ≥ 4):
   - `packages/per-client/src/client.test.ts` — `parseJsonSafe`, `qs`, `enrichParsed`, `perBaseUrlFromEnv`, `PerPaymentClient.request` (mock `fetch`).
   - `packages/agent/src/tools.test.ts` — `createPerTools` covering each Zod schema branch (good/bad input, PER error path).
   - `packages/agent/src/tools/pay-resource.test.ts` — happy path, host-allowlist gate, 402 path.
   - `apps/web/app/api/example-paid/route.test.ts` — 503-when-unconfigured, 402-when-no-credential, 200-when-paid.
3. **Add a `test` script** at root + per-package:
   ```json
   { "scripts": { "test": "vitest run" } }
   ```
4. **Install Stryker for TS**:
   ```bash
   pnpm add -Dw @stryker-mutator/core @stryker-mutator/vitest-runner @stryker-mutator/typescript-checker
   pnpm exec stryker init   # generate stryker.conf.json
   ```
5. **(Optional) `necessist`** to flag unnecessary statements in those tests once they exist.
6. **Re-run genotoxic.** With the call graph + a working test suite + Stryker, the skill produces:
   - Survived-mutant triage at `agent.src.tools:createPerTools` and `per-client.src.client:enrichParsed` (the highest-CC nodes).
   - "Unnecessary statements" reports from `necessist` on the new tests.
   - A list of *fuzzing targets* derived from low-test-strength + reachable-from-untrusted-entrypoint nodes — primarily `apps/web/app/api/example-paid/route.ts`.
